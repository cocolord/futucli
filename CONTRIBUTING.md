# Contributing

Contributions are welcome.

## Development

```bash
git clone https://github.com/cocolord/futucli.git
cd futucli
pip install -e ".[dev]"
```

## Running tests

```bash
pytest
```

## Before submitting

- Run `pytest` and ensure all tests pass.
- Format code with your preferred formatter.
- Keep changes focused — one feature or fix per PR.
